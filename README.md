# Customer Churn Analysis & Prediction using Power BI and Random Forest

An end-to-end Customer Churn Analytics project that uses **SQL, Python, Power BI, and Random Forest Machine Learning** to analyze customer behavior, identify churn patterns, and predict customers at risk of churn.

### Key Features

* Performed **data cleaning and ETL** using SQL and Power BI.
* Analyzed customer demographics, services, contracts, tenure, payment methods, and churn reasons.
* Built an interactive **Power BI dashboard** with KPIs, churn rate, customer segmentation, and business insights.
* Developed a **Random Forest classification model** using Python and Scikit-learn to predict customer churn.
* Generated churn predictions for existing and new customers to support **customer retention strategies**.

### Technologies

**Python | Pandas | NumPy | Scikit-learn | SQL | Power BI | DAX | Excel | Random Forest | Data Visualization**
